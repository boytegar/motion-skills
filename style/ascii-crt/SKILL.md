# CRT ASCII Terminal
A moon-base AI wakes after forty years to a signal from Earth, and replies by drawing “home” in characters.

Imported from [Lemo-Opuscar by Lemomo (LemoLab)](https://github.com/lemomo-ai/lemo-opuscar) (`styles/ascii-crt`), CC BY-NC 4.0. Style content is unchanged; only the file layout was adapted.

**Planning only.** This pack ships the docs and tokens, no render kit of its own. `motion-strategy`, `motion-hook`, `motion-script` and `motion-storyboard` work normally: read `docs/style-guide.md` for the DNA and `docs/style-prompt.md` for portable prompts.
