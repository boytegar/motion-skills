# Copperplate Engraving
A natural-history plate engraves itself: the burin cuts the copper, the bee builds up line by line, and a watercolour wash brings it to life.

Imported from [Lemo-Opuscar by Lemomo (LemoLab)](https://github.com/lemomo-ai/lemo-opuscar) (`styles/engraving`), CC BY-NC 4.0. Style content is unchanged; only the file layout was adapted.

**Planning only.** This pack ships the docs and tokens, no render kit of its own. `motion-strategy`, `motion-hook`, `motion-script` and `motion-storyboard` work normally: read `docs/style-guide.md` for the DNA and `docs/style-prompt.md` for portable prompts.
