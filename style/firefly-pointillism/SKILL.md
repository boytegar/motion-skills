# Firefly Pointillism
A firefly's blink is a question: a girl gets her answer as a deer, loses every light in a storm, and asks the whole dark with the last one.

Imported from [Lemo-Opuscar by Lemomo (LemoLab)](https://github.com/lemomo-ai/lemo-opuscar) (`styles/firefly-pointillism`), CC BY-NC 4.0. Style content is unchanged; only the file layout was adapted.

**Planning only.** This pack ships the docs and tokens, no render kit of its own. `motion-strategy`, `motion-hook`, `motion-script` and `motion-storyboard` work normally: read `docs/style-guide.md` for the DNA and `docs/style-prompt.md` for portable prompts.
