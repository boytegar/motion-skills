# Gilded Illumination
In a painted world where only gold shines, the sun goes out; a girl carries the last lamp up the mountain and gives it its light back.

Imported from [Lemo-Opuscar by Lemomo (LemoLab)](https://github.com/lemomo-ai/lemo-opuscar) (`styles/gilded-illumination`), CC BY-NC 4.0. Style content is unchanged; only the file layout was adapted.
