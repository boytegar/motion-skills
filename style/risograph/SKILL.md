# Risograph Print
A Sunday-morning bike ride through the city — bakery, park, riverside — each stop adding an ink until three misregistered plates overprint.

Imported from [Lemo-Opuscar by Lemomo (LemoLab)](https://github.com/lemomo-ai/lemo-opuscar) (`styles/risograph`), CC BY-NC 4.0. Style content is unchanged; only the file layout was adapted.
