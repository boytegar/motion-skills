# Vintage Engraving Collage
A 1918 airmail sheet printed with its plane upside down: bought for $24, cut up and scattered, and number 66 is still missing.

Imported from [Lemo-Opuscar by Lemomo (LemoLab)](https://github.com/lemomo-ai/lemo-opuscar) (`styles/vintage-collage`), CC BY-NC 4.0. Style content is unchanged; only the file layout was adapted.

**Planning only.** This pack ships the docs and tokens, no render kit of its own. `motion-strategy`, `motion-hook`, `motion-script` and `motion-storyboard` work normally: read `docs/style-guide.md` for the DNA and `docs/style-prompt.md` for portable prompts.
